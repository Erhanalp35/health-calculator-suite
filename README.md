# 🩺 Health Calculator Suite

A modern and responsive health web application that provides essential health calculators to help users better understand their physical condition.

## ✨ Features

- ⚖️ BMI (Body Mass Index) Calculator
- 🔥 Daily Calorie Calculator
- 🎂 Age Calculator

## 🚀 Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)

## 📱 Responsive Design

Fully responsive and optimized for:

- Desktop
- Tablet
- Mobile

## 🎯 Purpose

Health Calculator Suite offers simple and practical health tools that allow users to quickly calculate body metrics and basic health information through an intuitive interface.
